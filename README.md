# GamingControlPanel

**GamingControlPanel** is an offline AI-powered aim-training and computer vision analytics platform built with Python 3, OpenCV, PyQt6, and SQLAlchemy.

## Features
1. **Moving Target Simulation**: Multiple training modes (Static, Moving, Reaction, Precision, Multiple, Timed).
2. **Computer Vision Engine**: HSV color masking, noise removal, contour detection, and object tracking.
3. **Aim Simulation System**: Adjustable sensitivity, smoothing (LERP, Exponential), and crosshair tracking.
4. **Analytics & Statistics**: Performance tracking, historical logs, and accuracy percentages.
5. **Database Persistence**: SQLite database with SQLAlchemy ORM.
6. **Professional PyQt6 Dashboard**: Dark gaming UI with responsive navigation and interactive canvas.

## Quick Start
```bash
cd ~/GamingControlPanel
source venv/bin/activate
python3 main.py
```
